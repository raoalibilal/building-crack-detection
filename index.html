Building Crack Detection

A deep learning system that looks at a photo of a wall or concrete surface, finds cracks, and marks exactly where they are.

View code on GitHub Open notebook in Colab

How it works

Cracks are early signs of structural damage. Checking them by eye is slow and depends on the inspector. This system does the first check automatically from a single photo.

1

Detect

EfficientNetB0 decides if the photo has a crack or not, with a confidence score.

2

Locate

A U-Net model marks every crack pixel. Large photos are checked tile by tile so thin cracks are not missed.

3

Report

Crack area is measured and given a rough severity: Minor, Moderate or Severe.

Results

Data and models

PartDatasetModel
Crack or no crackConcrete Crack Images (Özgenel, 2018): 40,000 photos, half with cracks. Split 24,000 / 8,000 / 8,000.EfficientNetB0, transfer learning + fine-tuning. Baseline: custom 3-block CNN.
Crack location800 concrete photos with hand-drawn crack masks. Split 640 / 80 / 80.U-Net with pretrained MobileNetV2 encoder. Loss: cross-entropy + Dice.

Limitations: trained on concrete surfaces, so painted, tiled or very dirty walls can give false alarms. Severity is based on crack area only. This is a screening tool, not a replacement for a structural engineer.

Run it yourself

Train: open the notebook in Google Colab, choose a T4 GPU, and run all cells (about 30 minutes). Then check any photo:

pip install -r requirements.txt
python src/predict.py wall_photo.jpg

Prints the result, confidence, crack area and severity, and saves the photo with cracks in red.
